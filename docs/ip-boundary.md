# Public / Private Engineering Boundary

This repository is a curated engineering portfolio derived from a larger private project. Its purpose is to provide verifiable implementation evidence without publishing product-specific decision intelligence.

## Public in this repository

The public layer may contain real implementations of generic engineering concerns such as:

- FastAPI application and API patterns
- Pydantic request/response contracts
- SQLAlchemy persistence patterns
- image upload and storage infrastructure
- technical image-quality analysis
- multimodal AI client interfaces
- structured-output parsing patterns
- selected orchestration code
- human-review state transitions at an architectural level
- tests for public components

## Abstracted

Some components are represented only through reduced interfaces or high-level documentation:

- structured room knowledge / Digital Twin
- design-request context
- multimodal vision orchestration
- AI reasoning
- solution evaluation
- recommendation generation

The abstractions communicate component responsibilities and software boundaries without exposing the complete private implementation.

## Intentionally private

The following are not published:

- production prompts or prompt chains
- complete Domain AI Specification
- full internal Digital Twin schema
- AI-only domain attributes
- attribute-specific evidence requirements
- evidence readiness and sufficiency rules
- evidence-gap diagnosis
- targeted capture recommendation rules
- thresholds, weights and domain heuristics
- detailed internal reasoning stages and contracts
- prioritization and conflict-resolution rules
- optimization and evaluation policies
- internal orchestration/control rules that reveal the above
- credentials, tokens, private URLs, production configuration or user data

## Publication rule

A component is suitable for this portfolio when it provides meaningful evidence of engineering ability without materially enabling reconstruction of the private product logic.

In short: **show the engineering; keep the product-specific intelligence private.**
